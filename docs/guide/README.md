# Guide

How the fork works as you use it. AeroSpace's own user guide is upstream's, kept current by
upstream, and isn't copied here:

- `docs/guide.adoc`: concepts, the tree, workspaces, multiple monitors, config
  ([published](https://nikitabobko.github.io/AeroSpace/guide)).
- `docs/commands.adoc` and one aerospace-<cmd>.adoc page per command in `docs`
  ([published](https://nikitabobko.github.io/AeroSpace/commands)).
- `docs/config-examples/default-config.toml`: the built-in default config (the common keys with their defaults).

The pages here cover what's specific to the fork:

- [Running the fork](running-the-fork.md): building it, running the debug build beside the
  installed AeroSpace, and installing a source build in its place.
